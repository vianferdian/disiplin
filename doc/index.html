SASS installation -

1.- Install Node.js

To compile Sass via the command line first, we need to install node.js. The easiest way is downloading it from the official website nodejs.org open the package and follow the wizard.

2.- Npm install

To install all the dependencies listed in the package.json file, simply run the following command in the terminal: npm install

npm install
3.- Run the Script

To execute our one-line script, we need to run the following command in the terminal: npm run sass

npm run sass

HTML Structure -

All The Css, Js and configurations are added in the dz.php file under the config directory of root folder, there is multiple array of configurations, css and js in dz.php config file. So css and js are included in every pages by running the loop of arrays from dz.php config file. Under the configurations file, the keys of css and js arrays are the page or file name.when the page is open, get the current page name in the dz.php config file and run the loop for css and js.
